# Design System

## Design Philosophy

Conversation Inbox is not a messaging application.

It is a decision-support interface designed for enterprise Customer Experience (CX) agents.

Every design decision should reduce cognitive load and help agents identify and resolve high-priority conversations quickly.

The interface should feel calm, trustworthy, and efficient.

Inspired by:

- Linear
- GitHub
- Notion
- Superhuman
- Stripe Dashboard

---

# Design Principles

## 1. Prioritize Information

Users should immediately understand:

- What requires attention
- Why it requires attention
- What action to take

Visual hierarchy is more important than decoration.

---

## 2. Simplicity

Remove unnecessary UI.

Only show information that helps agents make decisions.

---

## 3. Speed

Frequently used actions should always be visible.

Support keyboard-first workflows.

---

## 4. Consistency

Every card, badge, spacing, and interaction should behave consistently throughout the product.
